# DXVision Readme

## 1\. Preface



#### Introduction



DXVision is a DirectX‑based rendering engine packaged as a DLL, providing real‑time blur, distortion, chromatic aberration, and texture rendering for external applications such as AutoHotkey.



#### Features



* Real‑time DirectX 11 rendering
* Fullscreen post‑processing pipeline
* Gaussian blur (separable, precomputed weights)
* Lens distortion (k1/k2/k3 radial model)
* Chromatic aberration
* Texture loading and rendering
* Error reporting system
* Clean C API for external applications
* CMake‑based build system



#### Project Structure



CMkL.API/

* CMakeLists.txt
* include/ (Public headers)
* src/     (C++ Implementation)
* shaders/ (HLSL source files)
* bin/     (Built DLL and compiled shaders)
* build/   (Generated by CMake, ignored in git)



## 2\. API Explanation



##### Device + context creation

* D3D11CreateDevice
* Feature level negotiation
* Debug layer (if available)
* Multithread protection



##### Swap chain creation for the overlay window

* DXGI factory
* Flip‑model swap chain
* Resize handling
* VSync / no‑vsync control



##### Overlay window creation

A fully‑functional:

* topmost
* borderless

* click‑through
* layered
* DirectX‑compatible window with DPI awareness and monitor detection



Window created with:

* WS\_EX\_LAYERED
* WS\_EX\_TRANSPARENT
* WS\_EX\_TOPMOST
* WS\_POPUP



## 3\. SRC explanation



##### Desktop Duplication capture

dxv\_capture.cpp will implement:

* IDXGIOutputDuplication
* AcquireNextFrame
* Handle timeouts
* Handle monitor changes
* Convert DXGI\_FORMAT\_B8G8R8A8\_UNORM to shader‑usable textures

This gives you a **live texture of the desktop** every frame.



##### Shader pipeline

dxv\_pipeline.cpp will implement:

* fullscreen triangle vertex shader
* blur pixel shader
* distortion pixel shader
* chromatic aberration pixel shader
* composite pixel shader

All loaded from .cso files compiled by CMake.



##### Texture system

dxv\_texture.cpp will handle:

* creating textures
* creating shader resource views
* creating render target views
* resizing textures
* copying captured frames into GPU textures



##### Constants + uniform buffers

dxv\_constants.cpp will implement:

* per‑frame constant buffer
* blur radius
* distortion strength
* chromatic offset
* time
* resolution
* mouse position (optional)



##### Error system

dxv\_errors.cpp will provide:

* internal error codes
* human‑readable messages
* last‑error tracking
* AHK‑friendly error retrieval



##### Utils

dxv\_utils.cpp will include:

* safe release macros
* logging
* timing
* fullscreen triangle setup
* window utilities



##### Main engine entry points

dxvision.cpp will expose:

* DXV\_Init()
* DXV\_RenderFrame()
* DXV\_Shutdown()
* DXV\_SetBlurAmount()
* DXV\_SetDistortion()
* DXV\_SetChromatic()
* DXV\_SetEnabled(bool)

These are the functions your AHK script will call.



## 4\. Shaders/window explanation



#### Shaders



Shaders are compiled by CMake into .cso files

DXVision loads them at runtime from:



bin/shaders/\*.cso



This is the **fastest** and **cleanest** method.

No runtime compilation.  
No embedded byte arrays.  
No dependency on d3dcompiler\_47.dll.



#### Overlay window



DXVision will:

* create its own window
* make it transparent
* make it click‑through
* make it topmost
* render into it
* capture the desktop behind it
* process the frame
* present the processed frame

You don’t need to create or manage any window yourself.

This is the **Wallpaper Engine / f.lux / accessibility filter** architecture.



## 5\. How to build (CMake)



##### Prerequisites



* Windows 10/11
* ~~Visual Studio Build Tools (or full Visual Studio) and Windows SDK~~
* Clang x64 within MSYS2, plus a few toolchains
* DirectX 11 runtime (included in Windows)
* CMake version 3.20+



##### Build



To build use the build.bat file, or type the commands below into the Clang shell mentioned above.

If you have the JSON config snippet for MSYS2 shells in Windows Terminal, type *win-x, i, ctrl-shift-9* to access Clang



*cmake -B build -DCMAKE\_BUILD\_TYPE=Release*

*cmake --build build --config Release*



The resulting DLL will appear in:



*bin/CMkL.API.dll*



#### Usage



##### Loading the DLL



###### Example (AutoHotkey):



*h := DllCall("LoadLibrary", "Str", "DXVision.dll", "Ptr")*

*DllCall("DXVision\\DXV\_Init", "Ptr", hwnd, "Int", width, "Int", height)*



##### API Overview



###### List of exported functions



* *DXV\_Init*
* *DXV\_Shutdown*
* *DXV\_RenderFrame*
* *DXV\_Present*
* *DXV\_SetBlur*
* *DXV\_SetDistortion*
* *DXV\_SetChromaticAberration*
* *DXV\_LoadTexture*
* *DXV\_RenderTexture*
* *DXV\_UnloadTexture*
* *DXV\_GetLastError*



##### Shaders



fullscreen\_vs.hlsl — fullscreen triangle vertex shader

blur\_ps.hlsl — Gaussian blur

distortion\_ps.hlsl — radial distortion

chromatic\_ps.hlsl — RGB channel offset

composite\_ps.hlsl — final image composition



#### Error Codes



Error codes are defined in *include/dxv\_errors.h*, but they are easier and interpret to find in the error-codes.csv file.

Use *DXV\_GetLastError()* (in AHK, if defined,  but that will call from this DLL, also just in C++ as-is) to retrieve the most recent error.

## 6\. Installing .cmake files

Type the install commands:



***cmake --install build --prefix "C:/Program Files/DXVision"***



***find\_package(DXVision REQUIRED)***



***add\_executable(MyApp main.cpp)
target\_link\_libraries(MyApp PRIVATE DXVision::DXVision)***



This gives you access to include dirs, linked DLLs and .lib files, and shaders (if installed)
